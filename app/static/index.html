Recon demo

The bank and our ledger send a statement file each day, by SFTP or the Upload button. The worker imports each file as it arrives, checks every line and, once both sides for a day are in, reconciles that day. The scheduled job catches up anything not yet reconciled and says which file never came. Refreshes every 3 seconds.
